3. Quantitative Strategy Mechanics & Structural Edge

The core alpha generation engine merges Donchian Channel momentum breakouts with Smart Money Concept (SMC) Order Block invalidation. A trade is generated only upon simultaneous confluence across five mathematical filters on completed, confirmed bar closes:

  • 1. Structural 20-Period Breakout: Price must close strictly outside the 20-period highest high or lowest low channel, confirming directional displacement: Close > max(High[1..20]) for Longs, or Close < min(Low[1..20]) for Shorts.
  • 2. Multi-EMA Trend & Velocity Slope: Filters out sideways chop. Requires Close > EMA 50, EMA 20 > EMA 50, and a strictly positive first-derivative velocity slope: EMA20 - EMA20[1] > 0 (inverted for Shorts).
  • 3. Anti-Exhaustion RSI Sweet-Spot: Prevents purchasing at the climax of parabolic thrusts. Long entries require 45.0 <= RSI(14) <= 75.0; short entries require 25.0 <= RSI(14) <= 55.0.
  • 4. Origin Order Block (OB) Anchor: Identifies the institutional accumulation/distribution footprint immediately preceding displacement (last down-candle for Longs, last up-candle for Shorts).
  • 5. Structural Invalidation (Stop Loss): Placed beyond the Order Block extreme + 0.50 x ATR(14) buffer. Protected by a minimum breathing floor (18.0 pips) and maximum volatility cap (60.0 pips).
  • 6. Fixed Target Matrix: Enforces a strict 1 : 1.75 Risk-to-Reward ratio: Take_Profit = Entry +/- (SL_Distance x 1.75).

6. Forward Performance Verification Ledger

Unlike commercial black-box bots that advertise fabricated backtests, this system operates under a strict Forward-Testing Standard. All performance metrics displayed via /performance are calculated exclusively from live forward executions recorded in trade_records.json starting from September 28, 2026:

  • Win Rate (%): (Winning Trades / Total Closed Trades) x 100
  • Net Realized Pips: Sum(Realized Exit Pips - Entry Pips) across all completed positions.
  • Net Realized Return (R): Sum(Realized R Multiples), where each winning trade yields +1.75 R and each loss is -1.00 R.
  • Profit Factor: Gross Winning Pips / Gross Losing Pips. Measures aggregate reward-to-risk efficiency.
Forward Auditing Integrity
Forward performance tracking guarantees zero survivorship bias and zero historical lookahead. Every metric published in the Telegram terminal is backed by an immutable git commit timestamp in trade_records.json.
